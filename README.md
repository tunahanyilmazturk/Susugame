# Susugame

## Karışık Kelimeler

Harfleri karıştırılmış Türkçe bir kelime gösterilir; iki oyuncu birlikte doğru kelimeyi bulmaya çalışır.

- `index.html` dosyasını tarayıcıda açmanız yeterli (kurulum gerektirmez, telefonda da çalışır).
- Doğru bilene 10 puan, ipucu kullanılırsa 5 puan. Pas geçilirse puan yok.
- Her turdan sonra sıra diğer oyuncuya geçer.
- Türkçe karakter yazmadan da tahmin edebilirsiniz (ör. `cicek` = `çiçek`).
